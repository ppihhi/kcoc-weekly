# OPERATIONS GUIDE

## 주간 일정

- 월요일: 최근 10일 기사 수집
- 화요일: 후보 3∼5건 검토·선정
- 수요일: 한국어 초안 작성
- 목·금요일: 사실·문체·권리·링크·모바일 전체 검수
- 토요일: 웹 공개와 카카오톡 수동 공유

품질을 확보하지 못하면 발행을 건너뛰며 발행번호를 증가시키지 않는다.

## 배포 전

```text
npm ci
npm test
npm run build
```

승인 상태와 커밋이 일치하고 자동검증 실패가 0건이어야 한다. 공개 URL을 휴대전화에서 확인한 뒤 공유한다.

## 비공식 고지 점검

소개, 정책, README, 발행호 출처 카드에 공식 매체가 아니라는 의미가 유지되는지 확인한다. 공식 로고나 공식 계정처럼 보이는 프로필 이미지를 사용하지 않는다.

## 보안

공개 저장소에 `.env`, 키, 토큰, 개인 연락처, 구독자·카카오 참여자 정보, 민감 초안을 저장하지 않는다.
