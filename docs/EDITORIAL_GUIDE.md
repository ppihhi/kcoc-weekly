# EDITORIAL GUIDE

## 문체

쉽고 친근한 존댓말을 사용하고 문장당 핵심 정보 하나를 전달한다. 제목은 객관적으로 12∼28자, 카드 본문은 120∼220자를 권장한다.

## 구성

기본 8페이지이며 표지, 배경·사실, 핵심 내용, 시사점, 질문, 출처를 포함한다. 종합형·단일기사형·INB형 모두 최종 출처 카드를 둔다.

## 표기

고유명사는 첫 등장에 한국어와 원어를 병기한다. 독자 날짜는 `YYYY년 M월 D일`, 데이터는 `YYYY-MM-DD`, 내부 기록은 ISO 8601과 `Asia/Seoul`을 사용한다.

## 비공식성

`KCOC`, `ICOC`, `Disciples Today` 등 고유 명칭을 사용할 때 공식 조직, 승인 매체, 한국 공식판으로 오인될 문맥을 피한다. 저장소명 `kcoc-weekly`는 콘텐츠 발행자명이 아니며, 화면의 발행자 표시는 **함께 보는 세계교회**로 통일한다.

## 시각 요소

원본 기사 사진 대신 CSS 도형, 색상 블록, 자체 아이콘, 타이포그래피와 적법한 오픈 라이선스 자산을 사용한다.
