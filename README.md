# 함께 보는 세계교회

세계 여러 지역의 교회와 공동체 소식을 한국어 웹 카드뉴스로 소개하는 개인 비영리 독립 프로젝트입니다.

> **비공식 고지:** 이 프로젝트는 특정 교회·기관·연합체·KCOC라는 명칭을 사용하는 조직·International Churches of Christ·Disciples Today가 직접 운영하거나 공식 승인한 매체가 아닙니다. 저장소명 `kcoc-weekly`는 기술적 식별자이며, 공식 한국판 또는 공식 주간지를 의미하지 않습니다.

## 저장소와 Pages

- 저장소: `kcoc-weekly`
- 예상 Pages URL: `https://{GitHub사용자명}.github.io/kcoc-weekly/`
- 표시 브랜드: `함께 보는 세계교회`

## 검증

```bash
npm ci
npm test
npm run build
```
